## 图像生成

### female-portrait-director

女性人像提示词导演 Skill：锁定用户明确参数，通过单一路由组织人物、动作、服装、场景、镜头、光线与滤镜，生成完整、可复制的摄影导演式提示词；支持已授权成年人物或产品参考主体的保留工作流。
