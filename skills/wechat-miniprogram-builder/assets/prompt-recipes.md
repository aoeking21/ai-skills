# AI 编程提示词模板

## 新功能

```text
你是微信原生小程序工程师。

项目目标：
[一句话定义目标用户、场景和核心任务]

本次只实现：
[一个可独立验收的增量]

输入：
[字段、类型、默认值、校验规则]

输出：
[页面结果、数据结构、成功状态]

必须处理的状态：
加载、空数据、非法输入、无权限、断网、超时、服务端错误、重复点击。

数据与安全：
[本地或服务端；禁止把任何密钥写入前端；说明权限用途]

技术约束：
[WXML/WXSS/JS 或 TS；现有目录；允许修改的文件]

视觉约束：
[布局、字号、间距、可访问性；不使用 Emoji 充当功能图标]

交付：
1. 修改文件清单。
2. 完整代码或最小补丁。
3. 关键设计说明。
4. 手工测试步骤。
5. 可能的回归风险。

验收标准：
[可观察、可重复的通过条件]
```
