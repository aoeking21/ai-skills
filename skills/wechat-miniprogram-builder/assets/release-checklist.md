# 上线检查清单

## 阻断级

- [ ] 核心流程在至少一台真机完整通过。
- [ ] 无崩溃、白屏、死链、测试入口和控制台阻断错误。
- [ ] 名称、简介、截图、类目和实际功能一致。
- [ ] 隐私声明、前端提示、代码调用和服务端存储一致。
- [ ] AppSecret、API Key、Token 和云密钥未进入前端包或仓库。
- [ ] 支付、广告、AI、用户内容和敏感类目已按当前官方规则核验。
- [ ] 正式域名、证书、服务端环境和数据库权限正确。

## 功能级

- [ ] 正常输入、空值、边界值、非法字符和重复点击已测试。
- [ ] 加载、空、错误、无权限、断网、超时状态均有明确反馈。
- [ ] 冷启动、热启动、返回前台和重新进入行为正确。
- [ ] 分享、保存、登录、支付、广告等实际能力已在真机测试。
- [ ] 页面返回、取消和退出不会丢失或重复提交数据。

## 体验级

- [ ] 首屏能快速解释产品用途和下一步操作。
- [ ] 核心任务路径足够短。
- [ ] 字号、点击区域、对比度和错误提示清晰。
- [ ] 广告不遮挡、不误触、不阻断核心任务。
- [ ] 弱网下有加载、重试和降级处理。

## 提审材料

- [ ] 版本号和版本说明准确。
- [ ] 审核测试路径清晰。
- [ ] 测试账号或体验数据可用。
- [ ] 权限和隐私用途说明完整。
- [ ] 特殊硬件、地区、时间或角色条件已说明。
- [ ] 已保留当前版本和可回滚版本。

## 发布后

- [ ] 错误日志和关键指标可观测。
- [ ] 用户反馈入口有效。
- [ ] 已定义核心完成率、错误率和停止条件。
- [ ] 首轮推广前完成小范围验证。
