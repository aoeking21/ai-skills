# GPT Image 2 街头纪实 V1.3

## 定位

本预设用于把 `aoeking-xiezhen-director` 与 `gpt-image-2` 编译成更接近真实城市偶遇的街头纪实人像。它优先保护人物身份、摄影事件与动作物理，主动压低服装和审美形容词的占比，并允许少量可控的不完美瞬间。

本预设只覆盖提示词编译策略。模型路由、尺寸和 API 参数继续由 [`GPT Image 2 专用 Adapter`](../adapters/gpt-image-2.md) 负责。

## 启用条件

出现以下任一意图时启用本预设：

- 用户明确指定“GPT Image 2 街头纪实 V1.3”。
- 用户要求真实街拍、城市偶遇、路口抓拍、人文纪实、雨后街头或强风街头。
- 用户反馈画面过度摆拍、服装抢戏、人物像模特、动作缺乏现场原因。
- 用户要求降低美化、提高身份保持、提高动作物理和摄影事件权重。

## 第一原则

街头纪实画面按以下因果链生成：

```text
人物身份真值
→ 现场刺激
→ 本能反应
→ 重心与关节结果
→ 衣料、头发和环境物理
→ 短暂表情与视线
→ 摄影者偶然按下快门
```

服装只参与物理反应和场景适配，不承担画面的主要叙事任务。

## 提示词预算

以下比例用于控制提示词篇幅与信息密度，不是 API 权重参数：

| 模块 | 建议占比 | 目标 |
|---|---:|---|
| 人物身份与身体结构 | 30% | 保留同一位成年人的脸、年龄、骨架、体态和稳定识别点 |
| 摄影事件 | 23% | 明确这一秒发生了什么以及人物为什么反应 |
| 动作与环境物理 | 22% | 说明支撑脚、重心、手部任务、风、水、衣料和接触关系 |
| 构图、镜头与现场光 | 15% | 建立真实街拍距离、透视、快门和环境密度 |
| 服装 | 7% | 只写款式、材质、覆盖和与事件有关的受力 |
| 审美形容词 | 3% 以内 | 只保留可转译为摄影结果的词 |

任何模块冲突时，优先顺序为：人物身份 > 摄影事件 > 动作物理 > 摄影语言 > 服装 > 审美修饰。

## 人物身份增强

人物参考图是身份唯一真值。身份段必须位于提示词前部，并使用可观察结构描述：

- 真实成年年龄感，不年轻化。
- 脸型、颧骨、下颌、发际线和面部自然不对称。
- 眼型、眼距、眉眼关系、鼻唇比例和稳定表情基线。
- 肤色、毛孔、细纹、痣和局部肤色差异。
- 肩颈、胸廓、躯干、骨盆、四肢长度和自然体态。
- 眼镜、发型、纹身或其他用户明确要求保留的识别点。

减少妆容、发型重塑、强烈情绪和审美模板，避免这些可变层覆盖身份真值。

## 摄影事件增强

每张图只保留一个主事件，并写清：

1. 现场刺激来自哪里。
2. 人物先感知到什么。
3. 哪只手解决什么现实问题。
4. 哪只脚承担重量。
5. 动作处于开始、进行中或尚未完成的哪个阶段。
6. 视线为什么落到某个方向。
7. 摄影者在哪一瞬间按下快门。

事件必须能够在现实街头发生。避免先写模特姿势，再给姿势补充理由。

## 动作与物理增强

动作段至少覆盖以下四项：

- 支撑脚与摆动脚。
- 躯干倾向与肩高差。
- 手部的现实任务。
- 风、水、衣料、头发、地面或人流中的一种明确互动。

强风、雨水、积水、电动车气流和人流避让必须具有方向、接触点和时间顺序。人物的表情与视线必须由事件产生。

## 服装降权规则

服装段控制在一至三句话内，只描述：

- 基础款式与材质。
- 必要的覆盖和穿着稳定性。
- 与本轮摄影事件直接相关的衣料受力。

不要反复描写领口、腰线、腿部或身体曲线。不要让服装取代人物身份和摄影事件。用户要求特殊服装时，完整执行款式要求，但仍保持人物身份、真实身体比例、正常覆盖和纪实语气。

## 美化词降噪

删除无法直接转译为摄影结果的词，例如：

- 绝美。
- 大师出片。
- 高级感。
- 氛围感拉满。
- 女神感。
- 电影感十足。
- 百看不厌。
- 完美身材。

需要表达风格时，改写成可观察结果，例如焦段、机位、曝光、光源方向、色温、快门、景深、构图偏移和背景运动状态。

## 可控真实失败概率

每张街头纪实图允许随机出现一至两项可控不完美：

- 动作停在尚未完成的中间阶段。
- 肩膀高度不完全对称。
- 一只脚尚未完全落稳。
- 发丝短暂掠过额头或面颊。
- 衣料边缘出现轻微、方向正确的运动模糊。
- 背景车辆或行人出现方向明确的动态模糊。
- 前景边缘出现少量路人、伞沿或车辆遮挡。
- 人物略偏离画面中心。
- 画面有轻微手持偏移或水平线不完全端正。
- 表情处于反应前后之间，没有完整微笑或标准情绪。

这些不完美用于模拟真实快门时机，不得演变为以下错误：

- 身份漂移、年龄漂移或身体比例漂移。
- 多余手指、断肢、关节错位或错误承重。
- 风向、水流和衣料受力冲突。
- 人物关键部位被完全遮挡。
- 走光、意外暴露或服装失去正常覆盖。
- 主体严重失焦、脸部不可辨认或整张画面技术性崩坏。

## GPT Image 2 编译顺序

启用本预设后，最终提示词按以下顺序输出：

1. 任务、画幅和单张画布。
2. 人物身份真值与稳定识别点。
3. 场景中必要的城市锚点。
4. 单一摄影事件。
5. 重心、关节、手部任务和环境物理。
6. 由事件产生的表情与视线。
7. 构图、机位、焦段、快门和允许的动态模糊。
8. 现场光线、曝光、皮肤纹理和区域反射。
9. 一至三句服装描述。
10. 一至两项可控不完美。
11. 少量高信号禁止项。
12. GPT Image 2 输出规格与逐次调用计划。

## 多张独立生成

用户要求五张独立图片时：

- 为五张图选择五个不同主事件。
- 至少改变事件刺激、动作阶段、支撑脚、视线目标、机位或前景关系中的三项。
- 每张只使用一至两项不同的可控不完美。
- 五条提示词分别完整编译。
- 五次独立调用，每次 `n: 1`。
- 不把上一张生成图作为下一张人物身份参考，除非用户明确要求连续编辑；人物身份始终优先来自原始授权参考图。
- 严禁五宫格、拼图和同一画布重复人物。

## 验收顺序

验收时按以下顺序评分：

1. 人物是否仍是一眼可识别的同一位成年人。
2. 年龄、眼镜、发型、骨架和体态是否保持。
3. 画面是否有单一、明确、可信的摄影事件。
4. 重心、手部、风、水、衣料和地面承重是否一致。
5. 人物是否没有持续镜头交流和模特展示姿态。
6. 可控不完美是否增强偶然性，而没有破坏人物或画面。
7. 服装是否服从事件，没有抢夺叙事中心。
8. 美化词是否已经压缩为具体摄影结果。
