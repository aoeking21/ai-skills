# Beauty Retouch Contract V1.0

本合同统一“医美级美颜、医美级自然精修、极致写真面部增强、真实皮肤”等历史术语，避免把修图质量误解成换脸或五官重塑。

## 1. 统一术语

正式术语：`医美级自然精修 / clinical-grade natural retouch`。

含义：以高完成度商业人像修图标准改善暂时性瑕疵、肤色、局部反射、眼神清晰度和整体精神状态，同时保留具体真人身份结构、自然年龄信息和真实皮肤微纹理。

“医美级”只描述完成度，不默认授权解剖重塑。

## 2. 默认允许

- 清理临时痘痘、明显脏点、传感器噪点和压缩伪影。
- 柔化偶发黑眼圈、疲态阴影和局部肤色不均。
- 优化曝光、白平衡、肤色通透感和区域高光。
- 提升眼神、睫毛、眉毛、唇纹、发丝等真实可见细节。
- 控制额头、鼻翼、面颊、下巴等区域反射，避免油膜。
- 在不抹平结构的前提下减弱暂时性皮肤粗糙。
- 保留合理毛孔、细纹、面痣、色素差异、法令纹走向和皮肤弹性。

## 3. 默认禁止

在身份保留任务中，除非用户显式要求对应修改：

- 改变脸宽、下颌、颧骨、鼻型、眼距、唇形等身份骨相。
- 生成标准化网红脸、明星相似脸或模板美女脸。
- 用夸张大眼、高鼻、尖下巴替换参考结构。
- 过度拉皮、年龄坍缩、幼态化。
- 塑料磨皮、蜡像皮、全脸同一反射率。
- 过度锐化毛孔、皱纹和微对比，制造“伪真实”。
- 让脸部精修程度与颈部、身体皮肤完全脱节。

## 4. 强度档位

- `natural`：轻修，原片纪实优先。
- `editorial`：高级写真标准，局部精修更明显，身份结构不动。
- `clinical-natural`：医美级自然精修，最高完成度，仍以身份一致和皮肤真实性为硬约束。

如果用户只说“医美级美颜”，默认解释为 `clinical-natural`。

## 5. 验收

同时满足以下条件才算通过：

1. 熟悉人物的人仍可一眼识别同一人。
2. 皮肤近看有微纹理，远看干净通透。
3. 眼周、鼻翼、嘴角、法令纹等结构仍符合年龄和表情因果。
4. 没有局部过度锐化或全脸糊成塑料。
5. 妆容和修图没有覆盖用户明确要求保留的痣、纹身或身份锚点。
