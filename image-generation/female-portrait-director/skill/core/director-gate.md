# 女性人像提示词导演 Skill｜导演模式强制门禁

版本编号：`FEMALE-PORTRAIT-DIRECTOR-V1.6`

本文件用于保证提示词生成、优化、图片反推和直接生图任务先完成画面设计，再进行扩写。

## 两阶段执行

### 阶段一：导演设计

- 锁定用户显式参数。
- 参考图任务先建立主体锁定。
- 确定唯一主 Route。
- 选择时间切片、主事件、动作链、视线落点。
- 决定配色、服装、环境、镜头、光线和质感。
- 执行成年边界和参数传递检查。

### 阶段二：融合扩写

最终提示词必须把人物、服装、动作、空间、镜头、光线和滤镜融合成同一个可拍摄瞬间。

## 输出前检查

- 单一主 Route。
- 参数完整保留。
- 画幅比例和尺寸要求落实。
- 参考图主体保持一致。
- 最终提示词属于完整摄影画面。
