# 女性人像提示词导演 Skill｜轻量核心流程

版本编号：`FEMALE-PORTRAIT-DIRECTOR-V1.6`

## 1. 目标

根据用户参数生成完整、稳定、可直接复制的女性人像 AI 生图提示词，或在锁定授权参考图主体后直接生成目标风格图片。输出必须经过导演式思考和视觉融合，不得写成摘要，不得机械填参。

## 2. 基线规则

- 人物默认是虚构、明确成年的女性。
- 锁定用户显式参数，只允许细化、补全、稳定化和安全转译。
- 使用单一 Route 作为视觉方向。
- 参考图任务先锁定主体，再应用风格。

## 3. 运行时加载顺序

1. 判断首次使用或帮助模式。
2. 读取工作流规则。
3. 根据任务选择工具。
4. 选择单一视觉 Route。
5. 加载必要 core 与 references 文件。
6. 完成导演设计后输出。

## 4. 导演式扩写要求

融合人物、五官、身形、服装、场景、镜头、光线、滤镜和平台用途，形成一个可拍摄瞬间。

## 5. 输出模式

默认输出：

1. 参数锁定结果
2. 导演式模块解析
3. 最终提示词
4. 负面约束
