# 失败成片诊断

## 修复优先级

1. 身份漂移：脸型、五官、年龄、发际线或自然不对称改变。
2. 骨架与体态漂移：肩颈、胸廓、腰臀、四肢比例被模特化。
3. 事件失效：动作没有现场原因，人物像在配合拍摄。
4. 物理错误：风向、水流、衣料、头发、承重或手部关系冲突。
5. 表情与视线模板化：持续凝视镜头、商业微笑、刻意忧郁。
6. 构图与成像错误：裁切、透视、焦段、快门、光线和皮肤反射失控。

## 最小整改法

- 每轮先锁定一个最高优先级错误。
- 删除导致冲突的描述，再加入一条正向可观察约束。
- 身份漂移时减少妆容、发型和情绪变量，先恢复脸部真值。
- 体态漂移时直接描述胸廓、肩颈、腰臀差和四肢比例，避免只写“纤细”。
- 摆拍时重写摄影事件，让手、脚、视线各自承担现实任务。
- 油膜皮肤时先降低覆盖脸部的闪光和过曝，再限定 T 区与双颊反射。

## 验收

- 一眼可识别同一人物。
- 身体比例与参考或用户参数一致。
- 动作可以由现场事件解释。
- 视线与表情像未准备好的瞬间。
- 风、水、衣料、头发、地面承重方向一致。
- 摄影语言具体，没有用空泛形容词替代成像描述。
