# 真实摄影事件 Schema

## 核心公式

环境刺激 → 本能反应 → 重心变化 → 衣料与头发受力 → 短暂表情和视线 → 摄影者偶然按下快门。

## 每张事件卡

1. 事件：这一秒发生了什么。
2. 刺激：风、浪、人流、车辆、温度、声音、台阶或道具。
3. 本能反应：压衣摆、避浪、收脚、拨发、侧身让路、短暂停步。
4. 身体结果：支撑脚、摆动脚、躯干倾向、肩高差、手臂张力。
5. 表情结果：疲惫、警觉、迟疑、放松或未完成的笑，必须有现场原因。
6. 视线：看向刺激源、前进方向、手中物或远处；镜头交流只能是极短偶然瞬间。
7. 物理：衣料厚度、风向、重力、湿水、脚下承重和环境互动一致。
8. 摄影结果：构图不完美、允许局部动态模糊，脸部和关键动作保持清晰。

## 约束

- 一张图只设置一个主事件。
- 手部动作必须解决现场问题，避免纯展示姿势。
- 表情不能独立于事件存在。
- 强风、海浪、汗水和衣料贴合必须具备方向与因果。
- 禁止叉腰、挺胸、收腹、扭胯、固定回眸和目录式展示服装，除非用户明确要求摆拍。
